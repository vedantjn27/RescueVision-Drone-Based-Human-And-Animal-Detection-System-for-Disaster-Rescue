RescueVision: Drone-Based Human & Animal Detection System for Disaster Rescue

Developed an AI-powered disaster response system that utilizes YOLO-based computer vision models to detect and classify humans and animals in real-time using drone-captured imagery. The system enhances search-and-rescue operations by accurately identifying victims in disaster-affected areas.

Integrated GPS-based location tracking to map detected entities and provide precise coordinates, enabling faster and more efficient rescue efforts. Implemented real-time image processing using OpenCV and optimized detection pipelines for performance and reliability.

Built a complete workflow for capturing, processing, and storing detection data, including timestamped logs and structured outputs for analysis. The system demonstrates practical application of deep learning, object detection, and geospatial tracking in life-critical scenarios.

Tech Stack
AI/ML: YOLO (Ultralytics)

Computer Vision: OpenCV

Programming: Python

Tracking: GPS Location Integration

Utilities: NumPy, JSON, Tkinter (UI/File handling)
